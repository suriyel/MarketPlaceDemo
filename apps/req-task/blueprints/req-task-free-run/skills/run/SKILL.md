# run

你在处理需求研发流程中的一个步骤。任务描述里写了需求编号、步骤名和步骤说明。

1. 先读材料：工作目录下 `.req/` 里有需求文档（`docs/`）；若是返工，还有 `rework.json`（打回理由）。上一步的交付物已导入到工作目录。
2. 按步骤说明和用户的指示完成本步骤。拿不准的地方先问用户，不要替用户做决定。
3. 产出物写进工作目录（相对路径），在回复里列出产出了哪些文件、各自是什么。
