登录 GitHub CLI（gh）

浏览器授权（推荐）
粘贴 Personal Access Token

点下面的「开始」后，gh 会：

  1. 打开系统浏览器到 GitHub 授权页；
  2. 把一次性验证码复制到剪贴板（需要你在 GitHub 页面粘贴）；
  3. 轮询等待你点 Authorize；
  4. 把 token 存到 Windows 凭据管理器（wincred），不经过本页面。

完成后下面的终端会自动关闭。如果你不想用浏览器流，切到「粘贴 token」页签。
